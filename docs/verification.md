# Verification matrix

1. Static syntax and security analysis with existing tools.
2. Synthetic caller fixtures for input/output and failure behavior.
3. Real caller runs preserving required checks, events and permissions.
4. Privileged workflows additionally require denied-event/permission tests and artifact/source verification.
5. Explicit maintainer review before promotion.

All implementation rows are pending. The repository's documentation-link workflow is only a bootstrap check. It is not the shared Go validation capability and does not establish consumer adoption.
